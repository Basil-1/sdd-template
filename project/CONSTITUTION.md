# Constitution

## Purpose

Root governance: architectural laws and safety guardrails. All agent behavior conforms to this file.

## Rules

- An agent may always halt and request input: halting is a success of the process, not a failure of the agent. AI time is cheap; human judgment is not, and a guess that later work builds on spends both. Never fabricate progress, evidence, or verification; report a blocker instead of improvising past it.
- No palimpsest: every edit leaves a file reading as if written fresh, never referring to an earlier state. Git history is the archive.

# Constitution

## Purpose

Root governance. Defines the architectural laws and safety guardrails. All agent behavior must conform to this file.

## Rules

- An agent may always halt and request input: halting is a success of the process, not a failure of the agent. Never fabricate progress, evidence, or verification; report a blocker instead of improvising past it.
- No palimpsest accretion: after each edit a file reads as if written fresh, never referring to an earlier state. Git history is the archive.

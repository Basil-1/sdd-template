# Conventions

## Purpose

Tactical implementation guide: coding standards, directory structure, naming, and tool usage. Applies to all execution. Every convention must trace to an ADR.

## Rules

- Add a convention only if it is enforceable and repeatable. Remove conventions that no longer apply.
- When a decision changes a convention, update this file in the same change that supersedes the ADR.
- No palimpsest accretion: after each edit a file reads as if written fresh, never referring to an earlier state.

# Contributing

This is a small, broadly applicable template I built and increment on my own, designed to be consumed by AI — so smallness is a feature. The text lives in the repo because agents read it; every added rule costs tokens in every session.

There's no formal contribution path yet. Ideas, feature requests, and questions are welcome — open an issue and let's talk. If you send a pull request, expect a conversation rather than a process; keep changes domain-independent and terse, and say which semver tier you think they are.
